# LUX MELODY — てのひらで おんがく

保育園児向けの、カメラの前で手を上げ下げして演奏できる音楽ゲームです。**v0.3**。

## 遊び方

1. 最初の画面で「🎵 きらきらぼし」または「🌈 じゆう えんそう」を選びます。
2. 「✋ てで あそぶ」を選ぶ場合は、スマホを机に置き、大人と一緒にカメラの利用を許可します。
3. パーの手をインカメラに向け、近い位置と遠い位置をそれぞれ記録します。
4. **カメラから遠い手＝高い音／近い手＝低い音**。**✋ パーで発音、✊ グーで消音**。握っている間は曲の判定も止まります。
5. カメラが使えない場合は「👆 タッチで あそぶ」を選び、表示された大きな音階ボタンを押します。

### 2つのモード

- **きらきらぼし**：最初の14音を、6音（ド〜ラ）の中から順に当てていきます。制限時間・ゲームオーバーなし。同じ音が連続しても次の音へ進みます。
- **じゆう えんそう**：**2オクターブ（C4〜C6、ドから2つ上のドまでの15音）**。曲の正解・不正解はなく、好きな音を自由に鳴らせます。

PCでのタッチ代替キーボード操作は、童謡が `1`〜`6`、自由演奏が `1`〜`9`、`0`、`q`、`w`、`e`、`r`、`t` です。

## 技術

- HTML/CSS/JavaScriptのみの静的Webアプリ。GitHub PagesのHTTPSで動作します。
- ブラウザでMediaPipe Handsが出力する21個の手ランドマークから、手のひらの見かけ上の大きさを測り、カメラとのおおまかな距離に変換しています。**絶対距離（cm）ではありません**。
- カメラ操作では、起動時に近距離・遠距離で調整します。光や角度の変化で精度は変わります。
- 2オクターブの自由演奏には15段階の音程量子化と境界ヒステリシスを導入し、細かな揺れによる頻繁な音の切り替わりを抑えています。
- `@mediapipe/hands` を jsDelivr から読み込みます。**カメラモードにはネット接続が必要**です。
- 音はWeb Audio APIによる端末内合成で、録音ファイルは使用していません。カメラ映像は外部送信・保存しません。
- 「きらきら星」は公有のフランス民謡「Ah! vous dirai-je, maman」の旋律に基づいています。

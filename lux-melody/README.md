# LUX MELODY v0.6 — おとの ながさで うたを おぼえよう♪

保育園児向け、流れてくる音符に手の高さ（またはタッチ）を合わせるブラウザ音楽ゲームです。季節の歌を含む13曲の短い練習フレーズと、2オクターブ自由演奏を収録。

## v0.6 で改良した内容

- **きらきら星**：1拍・2拍の音符を使い、伸ばす音を自然に表現。
- **ジングルベル**：繰り返す「ミ・ミ・ミー」に長短を設定。半拍の短い音と長い音を区別。
- **ちょうちょう**：短い音と伸ばす音の変化を追加。
- 上記3曲に専用のテンポ・簡易和音進行・音色を設定。音源はWeb Audio APIで合成するため、録音音源は使用しません。
- 音符の後ろに、音の長さがわかる色付きの帯を表示。
- 正解時は演奏を止めず、間違えたときだけ音符と伴奏が待つ。正解すると自然に続く。
- 春夏秋冬のほかの曲と自由演奏は継続して使用できます。

## 遊び方

1. 歌を選び、✋ てであそぶ、または 👆 タッチであそぶを押します。
2. カメラモードは、スマホを机に置き、手をカメラから遠ざけると高い音、近づけると低い音です。
3. パーで発音、グーで消音。流れてくる音符の高さに合わせます。
4. 正しい高さで判定ラインに来ると、メロディーが鳴り、そのまま次へ進みます。

カメラの利用にはHTTPSとブラウザの利用許可が必要です。カメラ映像は録画・送信しません。iPhoneなどの実機での手認識精度は別途検証が必要です。

**注意：** 現時点で3曲はリズムと伴奏を重点改善した幼児向けの短い簡易編曲です。全曲の原曲譜面との厳密な一致や商用録音レベルの音源品質を保証するものではありません。残りの季節の歌は従来の学習用リズムです。

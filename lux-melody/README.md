# LUX MELODY v0.5 — ながれるドレミと ばんそう♪

保育園児向け、カメラの前の手の高さ（または画面タッチ）で流れる音符を合わせる音楽ゲーム。季節の歌を含む13曲の練習フレーズ＋自由演奏。

## v0.5 の変更

- **正解したら即座に次の音符へ進む**。従来の「ぴったり！」による演出待ち（約0.5秒）を削除。音がつながり、短いメロディーになる。
- **不正解のときだけ音符が判定ラインで止まる**。正しい高さと手のパーを認識すると、待たずに先へ進む。
- **伴奏（🎹 ばんそう ON/OFF）**を新設。低音とやさしいアルペジオを Web Audio API で合成し、音符のスクロール進行に同期する。間違えて止まると伴奏の進行も止まる。
- 「きらきら星」など、フレーズの切れ目で長い音を扱えるよう一部の音の長さを変更。
- 途中の大きな成功テキストを削除し、4音ごとに小さな✨だけ表示。

## 操作

1. 好きな曲を選ぶ（季節ごとのタブあり）。
2. スマホを机に置き、手の距離（近い=低い音、遠い=高い音）を調整する。カメラ使用には許可とHTTPSが必要。
3. パーで音符を合わせる。グーは消音。タッチ操作でも遊べる。
4. 正解するとメロディーが鳴り、次の音符へ流れる。不正解だけ待つ。
5. 伴奏はプレイ中の「🎹 ばんそう ON/OFF」から変更可。上部の「🔊 おと」は全音量のオンオフ。

楽曲は短い学習用フレーズです。リズム・譜面には幼児向けの簡略化があり、原曲の完全な演奏ではありません。伴奏は独自の簡易和声であり既存の音源を使用しません。正式版では全曲の音程・拍子を校正してください。カメラの検出精度は実機での確認が必要です。映像はページ内で処理し、録画・保存・送信しません。

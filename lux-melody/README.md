# LUX MELODY v0.4 — てのひらで ドレミ♪

保育園児向けのブラウザ音あそび。**音符が右から横スクロール**して、手の高さ・画面タッチで自分の音符を上下させ、音の高さを合わせるとその音が鳴ります。音符は判定ラインで待ってくれるため時間制限はありません。

- **基本のうた**: ドレミのかいだん（オリジナル）、きらきらぼし、ちょうちょう、かえるのがっしょう
- **春**: はるが きた、はるの おがわ、さくら さくら
- **夏**: かたつむり、うみ
- **秋**: もみじ、むしの こえ
- **冬**: ゆき、ジングルベル
- **自由演奏**: 2オクターブ・15音

上記の童謡は**音の高さを学ぶための冒頭フレーズのみ**を収録し、音符の長さはゲーム向けに等しくしています。歌詞や市販音源は使っていません。音はブラウザのWeb Audio APIで新たに生成します。

## 使い方

1. 好きな曲を選ぶ。
2. スマホは画面を上にして机に置く。
3. 「てで あそぶ」を選ぶときはカメラを許可し、パーの手を近く→遠くの順に見せて調整する。
4. 手を高く（遠く）すると音符が上に、低く（近く）すると下に移動する。
5. 流れてきた音符の高さが合えば、正しいドレミが鳴り、次へ進む。曲モードはパーのまま遊べます。グーは一時消音です。
6. 認識が不安定な場合は「タッチで あそぶ」：画面上を上下になぞるか、▲▼ボタンで高さを選ぶ。

**公開**: `https://manaty-bit.github.io/time-ahead/lux-melody/`

単一HTMLファイルで構成。GitHub PagesのHTTPS上で動きます。手の認識にはネットワーク経由でMediaPipe Handsを読み込みます。カメラ映像はページ内で処理し、録画・保存・送信しません。カメラ利用は実機での検証が必要です。

## 著作権について

伝承曲や保護期間が満了した古い唱歌の旋律に基づいています。新しい編曲・録音・歌詞データは取り込んでいません。クラシックや日本の古い童謡であっても、編曲や録音音源には別途権利が生じる場合があります。参照：https://www.bunka.go.jp/seisaku/chosakuken/taisetsu/point/index.html

# LUX MELODY v0.7 — おてほんを きいて、ドレミを あわせよう♪

保育園児向け、手の高さ（またはタッチ）で横から流れてくる音符に合わせるブラウザゲーム。春夏秋冬を含む13曲の練習フレーズと2オクターブの自由演奏が遊べます。

## v0.7で変わったところ

- **おてほん再生**：曲選択画面の「▶ おてほん」から、選んだ曲の最初の14〜16音を伴奏つきで試聴できます。再生中は「■ とめる」。曲変更や画面移動で自動停止します。
- **幼児向けテンポ切替**：「🐢 ゆっくり」を押すと約38％ゆっくり流れます。もう一度押すと元の速度に戻ります。
- **譜面のリズム修正**：「ジングルベル」と「ちょうちょう」の拍数を整え、短い音・伸ばす音を区別しました。「きらきら星」の拍数と専用音色・和音は引き続き使用できます。
- **季節に合う音色**：春と秋はピアノ風、夏はオルゴール風、冬はベル風。重点3曲では専用のテンポ・簡易伴奏を使用します。
- **音符の長さの可視化**：長い音には「のばす」のガイドを表示。
- **停止条件はそのまま**：正解では演奏を止めず、間違えたときだけスクロールと伴奏が停止。正しい音にすると再開します。

## 使い方

1. 曲のカードを選び、**▶ おてほん**で最初のフレーズを聴きます。
2. **✋ てで あそぶ**または**👆 タッチで あそぶ**からスタート。
3. 流れてくる音符に、手や指で自分の音符を合わせます。
4. 難しいときは **🐢 ゆっくり** を押します。伴奏は「🎹 ばんそう ON/OFF」で切り替えられます。

カメラモードはHTTPSとブラウザのカメラ権限が必要です。映像はブラウザ内で処理し、送信・保存しません。

## 譜面・動作の注意

「きらきら星」「ジングルベル」「ちょうちょう」の冒頭を重点改善しましたが、音楽教科書の全パートを忠実に再現した完全版ではありません。ほかの季節の歌は従来の簡易練習譜面のため、今後校正が必要です。ブラウザの自動テストでは、曲選択・試聴・試聴停止・テンポ切替・停止と再開・画面移動を確認済みです。iPhone実機のカメラ検出や音量バランスの検証は別途必要です。

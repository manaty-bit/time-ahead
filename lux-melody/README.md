# LUX MELODY — てのひらで おんがく

保育園児向けの、手の高さで童謡を演奏するブラウザゲームです。

## あそびかた

1. スマホを机に置き、画面を上に向けます。
2. 大人と一緒に「✋ てで あそぶ」を選び、カメラを許可します。
3. インカメラに**手のひらを向け**、近い位置（低い音）と遠い位置（高い音）を記録します。
4. 「きらきらぼし」のお手本に合わせ、手を上下させます。**手をカメラから遠ざける＝高い音、近づける＝低い音**です。
5. 音が合うと星が光って次の音に進みます。時間制限、ゲームオーバーはありません。

カメラが使えない場合でも「👆 タッチで あそぶ」で音のボタンを押して演奏できます。PCではキーボードの1〜6キーも使用可能です。

## 技術

- HTML / CSS / JavaScript、単一の `index.html`。GitHub PagesなどのHTTPS静的ホスティングで動作します。
- ブラウザのMediaPipe Handsで**21か所の手ランドマーク**を検出し、画面内の手のひらサイズからおおまかなカメラとの距離を推定します（絶対的なcm測定はできません）。
- `@mediapipe/hands` を jsDelivr から初回ロードします。カメラモードにはインターネット接続が必要です。
- 音はWeb Audio APIを使って端末内で合成します。外部の録音音源を使用しません。
- 曲は公有のフランス民謡「Ah! vous dirai-je, maman」に基づく「きらきら星」の冒頭14音。独自合成音を使用します。
- カメラ動画・画像、手の情報はアップロード・保存しません。解析は端末内で実施します。
- iPhone Safari / Android Chromeを想定。ただし機種・環境・ネットワークによって手の検出精度は変動します。

## 制作メモ

最小実装版（MVP）です。カメラが顔を向く位置にある端末、暗い部屋、カメラに手が近すぎる場合などでは判定が難しくなることがあります。起動時の2点調整で対応しています。
